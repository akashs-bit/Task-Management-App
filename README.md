# 📝 MERN Task Management App

A simple and powerful Task Management application built using the MERN Stack (MongoDB, Express.js, React, Node.js). This app lets users create, view, update, and delete tasks with real-time status updates.

---

---

## 🚀 Features

- ✅ Add New Tasks with Title and Description
- 📋 View All Your Tasks
- ✏️ Edit Task Details and Status
- ❌ Delete Unwanted Tasks
- 📈 Status Options: `Pending`, `Running`, `Completed`, `Failed`
- 🧠 Validations using `zod`
- 🔥 Toast Notifications for actions
- 📦 RESTful API Integration
- 💻 Responsive UI using Tailwind CSS

---

## 🛠️ Tech Stack

### Frontend
- ⚛️ React.js
- 💨 Tailwind CSS
- 🧪 Zod (Form Validation)
- 🍞 React-Toastify (Notifications)

### Backend
- 🟢 Node.js
- ⚙️ Express.js
- 🗂️ MongoDB with Mongoose
- 🌐 CORS + dotenv
